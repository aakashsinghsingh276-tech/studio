# **App Name**: ChatOn

## Core Features:

- Instant Messaging: Real-time text messaging with contacts.
- Contact Synchronization: Automatically sync contacts from the user's phone.
- Multimedia Sharing: Share photos and videos directly within chats.
- Smart Reply Suggestions: AI-powered tool suggests quick replies based on message content.
- Status Updates: Users can post temporary status updates (text, photo, video) visible to their contacts.
- End-to-End Encryption Simulation: Simulate the presence of end-to-end encryption, for demonstration purposes
- Avatar Status: Users can set custom avatars with status indicators.

## Style Guidelines:

- Primary color: Soft teal (#70CBC9) to create a calming and friendly atmosphere, but avoiding cliché uses of the color teal.
- Background color: Very light greenish-grey (#F7F9F9) provides a clean and modern feel.
- Accent color: Light blue (#A0D1CA) to highlight key interactive elements and message bubbles for other users.
- Body and headline font: 'PT Sans', a humanist sans-serif for a modern look with a touch of warmth.
- Use simple, outlined icons for a clean and minimalist interface.
- Clean and intuitive layout with a focus on ease of use and readability.
- Subtle animations and transitions to provide a smooth user experience.
